Why it matters

The problem it solves.

Subscription requests arrive as long forms and email threads, with missing or invalid cost centres, owners and network sizes. Platform teams spend days chasing details and translating them into landing-zone configuration.

  • Validated at intake

    Every field is checked against CMDB, Finance, repository and platform data. The agent never invents a value.

  • Configuration derived for you

    Management group, network size, budget and tags come from platform standards, not from the requester.

  • No Azure write access

    The agent only files a ServiceNow request. A reviewed pull request and a pipeline make the change.

  • Approval at every gate

    The requester confirms a summary card, ServiceNow approval is required, and a human merges the PR.

How it works

From trigger to approved change.

The same operating model as every use case in the showcase, applied to Azure Vending Machine.

  1. Trigger

    A requester asks the Copilot Studio agent in Microsoft Teams

  2. Analyze

    Validates each field and derives configuration from platform standards

  3. Approve

    The requester confirms, then approvers sign off in ServiceNow

  4. Apply

    A human merges the azure.yml pull request; a pipeline runs sub-vending

      Safety
      
      
      Built to keep people in control.
      
      
      
      
        
      Read-only by design
      • The conversational agent holds no Azure write permission
      • It never invents identifiers, cost centres, owners, CIDRs or approval state
      • IPAM, not the agent, allocates the exact address range
      
        
      A human decides
      • The requester confirms the summary card before a ticket is filed
      • ServiceNow approval is required before any pull request is created
      • A human reviews and merges the azure.yml pull request

      Is it for you?
      
      
      Who it helps and what it takes.
      
      
      
      
        
      Who it's for
      • Azure platform and landing-zone teams
      • Power Platform and Copilot Studio makers
      • ServiceNow and DevOps engineers
      
        
      What you need
      • A Power Platform environment and a Copilot Studio licence
      • A ServiceNow instance and dedicated service account
      • A GitHub or Azure DevOps repository with a review workflow
