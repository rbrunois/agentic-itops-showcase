# Incident report template (review-only draft)

## Summary
State the symptom, scope, UTC window, and confidence.

## Impact
Separate customer-reported impact from observed request failures.

## Timeline
List timestamped observations, deployment/configuration changes, and uncertainty.

## Evidence
Include scoped queries, result summaries, metrics, and source path:line at a
specified commit. Do not invent results or publish credentials/customer data.

## Root cause
Distinguish confirmed cause, likely cause, and alternatives not yet excluded.

## Remediation
Propose a bounded operator action, approval needed, risk, and rollback plan.

## Action items
Recommend a reviewed code fix and verification. Do not automatically create PRs.

## References
Use redacted resource names and public source links. Human review is required
before any issue or comment is published to the explicitly selected repository.
