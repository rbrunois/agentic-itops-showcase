# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

All participants are expected to be respectful, inclusive, and constructive in
issues, pull requests, reviews, and any other project space.

## Reporting

Report unacceptable behavior privately to the repository maintainer through the
contact options on the [maintainer's GitHub profile](https://github.com/rbrunois).
Reports are reviewed promptly and handled confidentially. Maintainers may
remove, edit, or reject contributions, and temporarily or permanently restrict
participation, in line with the Contributor Covenant enforcement guidelines.
